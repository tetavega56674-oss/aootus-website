Three-level product structure

Product Families, System Types, and Complete Sets

AOOTUS products are organized in three levels: the curtain industry product family, the specific system type, and the complete product set with matched accessories.

Typical inquiry content

Project type, installation method, track or rod system, accessory match, and required quantity.

Start with the product family, then select the exact system

Level 1 identifies the main curtain product family. Level 2 defines the installation style, profile, size, shape, or use condition. Level 3 lists the complete product and its matched accessories.

Level 3 is the RFQ package

Each system type can be quoted with its profile, running parts, mounting hardware, connectors, end parts, curtain components, and packing.

Accessories belong to Level 3

Runners, gliders, rollers, brackets, connectors, end caps, hooks, rings, tapes, screws, and anchors are listed under the system they fit instead of being treated as a separate main product family.

Project solutions are a separate selection route

Hotel, hospital, room divider, large-window, and commercial projects use the same product hierarchy, but the final system is recommended by application. View project solutions.
