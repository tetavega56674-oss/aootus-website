# Aluminum Curtain Track Page Images

These files are dedicated image slots for `aluminum-track-system.html`.

Replace images using the same filenames when new real product photos are ready. Keep images in this folder and use relative paths from the HTML page.

Recommended sizes:

- `aluminum-track-hero.jpg`: 1600 x 1000 px, 16:10 ratio, main complete system photo.
- `aluminum-track-profile.jpg`: 1400 x 1050 px, 4:3 ratio, aluminum profile or cross-section detail.
- `aluminum-mounting-parts.jpg`: 1600 x 1000 px, 16:10 ratio, ceiling or wall mounting parts.
- `aluminum-curtain-components.jpg`: 1600 x 1000 px, 16:10 ratio, carriers, gliders, hooks, rings, tapes, or matched components.
- `aluminum-runner-carrier-set.jpg`: 1400 x 1050 px, 4:3 ratio, runner or carrier set.
- `aluminum-accessory-package.jpg`: 1400 x 1050 px, 4:3 ratio, bracket, connector, end cap, hook, screw, and tape package.
- `aluminum-ceiling-mount-option.jpg`: 1400 x 1050 px, 4:3 ratio, ceiling mount track or bracket detail.
- `aluminum-project-installation.jpg`: 1400 x 1050 px, 4:3 ratio, real project or room installation scene.
- `aluminum-compatibility-extension.jpg`: 1400 x 1050 px, 4:3 ratio, motor-compatible or extended system option.

Image guidance:

- Use real product or real project photos.
- Avoid catalog pages with too much text inside the image.
- Keep product centered with enough margin so cards do not crop key details.
- Use clean white, gray, or light neutral backgrounds when possible.
