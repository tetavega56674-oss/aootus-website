# AOOTUS Product Image Assets

This folder stores website-ready product photos for AOOTUS static pages.

Keep original camera files in the working source folder. Copy only selected, resized, and web-ready images into `assets/product/`.

## Folder Use

- `categories/`: product category card images used on Home and Products pages.
- `applications/`: project application card images used on the Applications page.
- `systems/`: featured system card images used on the Home page.
- `factory/`: factory overview images used on the Home page.
- Root product images: temporary project or application images already referenced by current pages.

## Recommended Category Image Size

- Preferred size: `1400 x 1050 px`
- Ratio: `4:3`
- Format: `.jpg` or `.webp`
- Suggested file size: `100KB-400KB`
- Use real product photos without Chinese labels or instruction-sheet screenshots.

## Home Factory Overview Images

The Home page factory overview image group uses one large image and two smaller images.

- Large image ratio: `16:9`
- Recommended large image size: `1600 x 900 px`
- Small image ratio: `16:10`
- Recommended small image size: `800 x 500 px` or `1000 x 625 px`

Use real factory, production, inspection, packaging, warehouse, or product system photos. Avoid instruction diagrams, Chinese labels, and images with large empty white margins.
